Hungry Brunch Café & Restaurant website
========================================

Files:
- index.html: page content
- style.css: visual design and responsive layout
- script.js: mobile navigation and order calculator/WhatsApp message
- images/: photos used by the page

To preview:
Open index.html in a browser. Keep the CSS, JS, and images folder in the same directory.

To publish with GitHub Pages:
Upload index.html, style.css, script.js, and the entire images folder to the repository root.
GitHub Pages should use the main branch and /(root).

Important:
- The WhatsApp order button opens a prefilled message to the publicly listed phone number. Confirm that the business uses WhatsApp on that number. This is not a backend ordering/payment system.
- Menu prices and opening hours are indicative and should be confirmed with the restaurant.
- Customer reviews are linked to Google Maps rather than fabricated or copied; use the link to see current reviews.
- If images/ contains placeholder filenames, replace them with actual photos and make sure the filenames match the src values in index.html.
